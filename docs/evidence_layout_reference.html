🧮 সিদ্ধান্ত কীভাবে হয় (MILP)

PuLP Mixed-Integer Linear Programming — ৬ মৌসুমের সবচেয়ে ভালো ফসল-সারি একসাথে খোঁজে।
১ · বিকল্প
প্রতিটা মৌসুমে কোন কোন ফসল সম্ভব (রবি/খরিফ-১/খরিফ-২-এর নিয়ম মেনে)
২ · স্কোর
ফলন (FAO-33), পানির চাহিদা (FAO-56), মাটি (ডালে N, খালি দিন), লাভ (দাম)
৩ · বাছাই
সব মিলিয়ে সর্বোচ্চ ওজনদার স্কোর: max Σ w·(লাভ, −পানি, মাটি)
৪ · নিয়ম
এক মৌসুমে এক ফসল · ডাল ফসলের ফাঁক · একই পরিবার পরপর নয় · সেচ সুবিধার সীমা · বিক্রি-অযোগ্য ফসল বাদ

৪ কৌশল = ৪ সেট ওজন (সুষম, লাভ, পানি সাশ্রয়, মাটির স্বাস্থ্য); অ্যাপে code থেকে আসল ওজন দেখাবে।
