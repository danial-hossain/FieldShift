FieldShift RL Experiment Updates
Date: 2026-10-07

- Fixed the React runtime error on the Experimental RL Policy & Adaptive Stress Simulation page. The Start Simulation click event was being passed into the season-count argument and could enter experiment state. The Start and intervention buttons now invoke handlers without passing the click event.
- Added a simulation-state boundary normalizer. Numeric state fields accept only finite numbers or numeric strings; source labels, field IDs, and crop/context fields accept only their expected primitive types. Event-shaped values become unavailable instead of entering experiment state or API payloads.
- Updated input handlers to extract control values before storing them. Added validation for run horizon and post-season stress/intervention inputs.
- Kept the initial S0 snapshot immutable during a run and added a separate Current State panel with provenance. State transitions remain sequential: each next RL decision uses the latest completed state and history; future actions and outcomes remain ungenerated until requested.
- Clarified selected run horizon versus the six-season maximum. Progress now shows the selected horizon (for example, 1 / 1) without implying the full six-season experiment is complete. Paused runs can be extended.
- Separated the RL proposed-action trajectory from the applied-action trajectory and display the decision source (RL Policy or User Override).
- Preserved candidate feasibility when a user overrides an action. Infeasible policy proposals and overrides show current simulated water availability and estimated demand; overrides are identified as counterfactual simulation, not recommendations.
- Clarified the candidate table headings for policy score, feasibility, estimated water demand, synthetic yield estimate, and simulated reward.
- Labeled crop, stress, and soil-health proxy transitions as simulation-derived, distinct from observed inputs. Added pH and organic-matter provenance where available; missing values remain unavailable.
- Kept comparison limited to the currently selected MILP strategy. Full-trajectory PuLP/CBC re-optimization remains unavailable until six seasons are completed.
- Added regression coverage for event-shaped values and infeasible manual overrides. Updated provenance assertions for simulation-derived stress/state transitions.
